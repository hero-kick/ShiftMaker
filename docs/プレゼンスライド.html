SECURITY
看護師の名前、絶対に外に出ない設計
「クラウドだから心配」を、設計レベルで解決。データをサーバに保存する仕組みそのものが存在しないから、漏洩のしようがない。
📱
端末のみに保存
スタッフ名・希望・シフトは、ブラウザのlocalStorageだけに保存。サーバへ送信されない、保存されない。
🔐
HTTPS暗号化
通信はすべて暗号化。生成リクエストのみ送るが、計算後にデータは即廃棄。
🔢
PINで端末保護
SHA-256で暗号化保存。原文は残らない。スマホ紛失時も中身は見えない。
👥
ユーザー完全分離
同じURLでもワークスペースごとに独立。他人のデータは見られない。
📜
ログに残らない
サーバはリクエスト本文を一切ログ出力しない。アクセス記録に名前が残ることもない。
🚫
第三者SDK不使用
広告、解析、トラッカー一切なし。データを集める仕組みがない。
