    SECURITY
    データはあなたの端末にだけ
    看護師の名前や希望データなどの個人情報が、外に漏れる経路を物理的に持たない設計。
    📱
    端末内ローカル保存
    スタッフ名、希望、シフトはブラウザのlocalStorageのみに保存。サーバへ一切送信されない。
    🔐
    HTTPS通信
    シフト生成時のみサーバと通信するが、結果受信後にデータは破棄される。サーバには残らない。
    🔢
    PINコード保護
    SHA-256でハッシュ化して保存。原文は保存しない。万一の端末紛失時も中身が見えない。
    👥
    ユーザー間の分離
    同じURL利用者でも、ワークスペースが違えばお互いのデータは完全に独立。覗き見不可。
    📜
    アクセスログに残らない
    サーバはリクエスト本文をログ出力しない。スタッフ名がログに残ることはない。
    🚫
    第三者SDK不使用
    広告、アナリティクス、トラッカーなど外部サービス不使用。データを集める仕組みがない。
    MULTI USER
    複数人で安全に共有
    同じURLを共有しても、お互いのデータは見えません。ワークスペース機能で完全分離。
