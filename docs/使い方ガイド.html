ShiftMaker とは

看護師の月間シフト表を、自動で作成するアプリです。 スタッフを登録し、希望休や有給を入力すると、 AI が「夜勤の翌日は明け」「夜勤回数の上限」などのルールを満たす最適なシフトを生成します。 手作業だと数時間かかる月間シフトが、数分で組み上がります。

こんな人におすすめ

  • 毎月のシフト作成を任されている看護師長・主任の方
  • 夜勤・日勤・有給のバランスを公平に組みたい方
  • Excel での手作業からそろそろ脱却したい方

主な特長

  • 自動最適化 — 5〜55秒でシフト生成
  • スマホ完全対応 — どこからでも編集可能
  • ユーザーごとにデータ分離 — 他人にデータが見えない
  • データはあなたのスマホ内のみ — サーバには一切保存されない
  • 無料 — 月額0円

スマホ・PC でアクセスする

ShiftMaker はインストール不要のウェブアプリです。ブラウザで URL を開くだけで使えます。

🔗 公開 URL
https://shiftmaker-s6fs.onrender.com

※ URL が変わった場合は管理者にご確認ください

スマホでのアクセス手順

  1. Safari（iPhone）または Chrome（Android）を開く
  2. アドレスバーに上記 URL を入力、または LINE などで共有されたリンクをタップ
  3. 「ワークスペース作成」画面が表示されれば成功

PC でのアクセス手順

  1. Chrome、Edge、Safari、Firefox など、好きなブラウザを開く
  2. 同じ URL を入力
  3. 同じ画面が表示されます（PCの方が画面が広くて編集しやすい場合があります）
⚠️ 初回アクセスは時間がかかります

15分以上誰もアクセスしていない場合、サーバが「スリープ」状態になっています。 最初の人がアクセスすると 30〜60秒間、真っ白な画面のままになります。 その間に閉じてしまうと永遠に開きません。焦らず1分待ってください。

ホーム画面に追加（アプリ化）

URLをブックマークするより、スマホのホーム画面にアイコンを追加すると、 通常のアプリのように1タップで起動できて便利です。

iPhone（Safari）の場合

  1. Safari で ShiftMaker を開く
  2. 画面下部の 共有ボタン（四角に上向き矢印 □↑）をタップ
  3. メニューが出るので、下にスクロールして 「ホーム画面に追加」をタップ
  4. 名前を確認して 「追加」をタップ
  5. ホーム画面に ShiftMaker のアイコンが追加されます

Android（Chrome）の場合

  1. Chrome で ShiftMaker を開く
  2. 画面右上の 「︙」（縦三点リーダー）をタップ
  3. メニューから 「ホーム画面に追加」または「アプリをインストール」を選ぶ
  4. 名前を確認して 「追加」をタップ
  5. ホーム画面にアイコンが追加されます

ワークスペースを作る

ワークスペースは「あなた専用のデータ保管箱」です。 他の人と同じ URL を使っていても、ワークスペースが違えばお互いのデータは見えません。

初回アクセス時

  1. URL を開くと、最初に「ワークスペース作成画面」が表示されます
  2. 名前を入力します（例：「自分用」「内科病棟」「3階A病棟」など）
    ※ あとから変更はできません。短くて分かりやすい名前にしましょう
  3. 必要なら PIN コードを入力（任意。後述）
  4. 「作成して開く」をタップ
  5. メイン画面が表示されます。次は「使い方ガイド」と「始める」のどちらかをタップ

2回目以降のアクセス時

  1. URL を開くと、ワークスペース一覧が表示されます
  2. 自分が作成したワークスペースをタップ
  3. PINコードを設定していた場合は入力
  4. メイン画面が開きます
💡 同じスマホで複数のワークスペースを使える

ご家族や同僚と1台のスマホを共有する場合、それぞれが自分のワークスペースを作れます。 画面右上の「👤名前」ボタンから切り替え可能です。

PIN コードについて

ワークスペース作成時に任意で設定できる、ご自身用の暗証番号です。

設定するメリット

  • スマホを他人が触ってもデータが見られない
  • スマホを紛失した場合の保険になる
  • 家族と1台を共有していても、お互いのデータを保護できる

注意点

🚨 PIN を忘れると復旧できません

PIN は安全のため 暗号化（ハッシュ化）されて保存されており、 開発者でも復号できません。忘れた場合は そのワークスペースを削除して作り直すしかなく、 中のデータは失われます。

覚えやすく、忘れにくい4〜6桁の数字がおすすめです。 （例：誕生日の月日、よく使う数字の組み合わせ）

PIN 入力のタイミング

タブを閉じて再度開くたびに、PIN の入力が必要です。 タブを開いたままなら再入力は不要です。

全体の流れ（7ステップ）

シフトを1ヶ月分作るまでの流れです。初回は20〜30分、慣れれば5〜10分で完了します。

📅 ShiftMaker 2026年5月
①スタッフ管理 ②希望入力 ③イベント ④日別条件 ⑤シフト表 ⑥集計 シフト生成
  1. ①スタッフ管理: 勤務するスタッフを全員登録（最初の1回だけ）
  2. ②希望入力: 各スタッフの希望休・有給を入力
  3. ③イベント: 会議・研修など特別な日を登録（任意）
  4. ④日別条件: 各日の必要人数を調整（基本は初期値のままでOK）
  5. 右上「シフト生成」: ボタンを押して数十秒待つ
  6. ⑤シフト表: 生成された結果を確認、必要なら手動修正
  7. ⑥集計: 各スタッフの夜勤回数・休日日数を確認
✅ 2ヶ月目以降は楽になります

スタッフ情報は保存されているので、毎月は「希望入力 → 生成」だけで済みます。

①スタッフ管理

シフトに入れる全スタッフを登録します。初回は時間がかかりますが、一度登録すれば翌月以降は不要です。

⚡ おすすめ: 「まとめて追加」で時間短縮

初回は全員分の名前を入れるのが面倒です。 「まとめて追加」機能を使うと、役職と人数を指定するだけで 「看護師1, 看護師2, 看護師3 ...」と暫定的な名前で一気に登録できます。 本名はあとで1人ずつタップして書き換えれば OK。 役職ごとに繰り返せば、混在病棟も簡単に整います。

登録手順A: まとめて追加（おすすめ）

  1. 下部タブから 「①スタッフ」をタップ
  2. 画面上部の 「⚡ まとめて追加」ボタンをタップ
    PC では「⚡ まとめて追加」タブを選択
  3. 以下の項目を入力:
    • 役職名: 例「看護師」「主任」「准看護師」
    • 人数: 例 8
    • 夜勤上限・連勤上限・夜勤可否を共通設定として指定
  4. 「○名 一括追加」ボタンをタップ → 看護師1〜看護師8 が登録されます
  5. 必要なら別の役職でもう一度繰り返し（主任2名など）
  6. あとでスタッフカードをタップすると、暫定名から本名に編集できます

登録手順B: 1人ずつ追加

  1. 下部タブから 「①スタッフ」をタップ
  2. 画面上部の 「+ 1名追加」ボタンをタップ
  3. 以下の項目を入力:
    • 名前（必須）: 例「田中 花子」
    • 役職（任意）: 例「看護師」「主任」
    • 夜勤上限: 月に何回まで夜勤に入れるか（例 8）
    • 連続勤務上限: 何連勤までOKか（例 5）
    • 夜勤可能: チェックを外すと夜勤に入りません
  4. 「追加」ボタンをタップ
  5. 同じ手順で全員を登録

登録手順（PC）

画面上部にフォームが常時表示されています。 各欄を埋めて「追加」ボタンを押すと、下のリストに追加されます。

編集・削除

  • 編集: スマホは登録済みのカードをタップ。PCは「編集」ボタンをクリック
  • 削除: 「削除」ボタンを押すと確認ダイアログが出ます
⚠️ スタッフを削除するとそのスタッフの希望データも消えます

間違って削除した場合は、もう一度登録し直して、希望も再入力する必要があります。

各項目の決め方

夜勤上限 (max_night)

1人あたりの月の夜勤回数の上限です。通常は 8 が目安。 全員を揃えるとシフトのバランスが良くなります。
例: 月8回 × 夜勤可能スタッフ 5名 = 月40回の夜勤枠 → 1ヶ月(31日) × 2人 = 62回必要 → 足りない

連続勤務上限 (max_consecutive_days)

何連勤までOKかの上限です。通常は 5 が目安。 5にすると、6連勤以上にペナルティが入り、可能な限り避けられます。

夜勤可能 (night_available)

日勤専従のスタッフ（管理職、夜勤免除中、など）はチェックを外します。

💡 初心者向け：まずサンプルデータで試す

ヘッダーまたは「…」メニューから 「サンプル読込」を実行すると、 10名のスタッフと希望データが自動で入ります。 機能を試してから自分のデータに置き換えると分かりやすいです。

②希望入力

各スタッフの「この日は休みたい」「この日は有給を取りたい」を入力します。

入力手順

  1. タブから 「②希望」をタップ
  2. 画面上部のスタッフ一覧から、希望を入力したいスタッフをタップ
    ※ スマホでは横スクロールできます
  3. 希望の種類を選ぶ:
    • 希望休: 可能な限りこの日を休みにする
    • 有給: この日に有給を割り当てる（必ず）
  4. カレンダー上で 希望の日付をタップ
  5. もう一度タップすると取り消しになります
  6. 別のスタッフに切り替えて、同じように入力
💡 希望休と有給の違い

希望休は「ソフト制約」です。可能な限り反映しますが、必要人数が足りない場合は通常の出勤になることがあります。
有給は「ハード制約」です。必ずその日に Y（有給）が割り当てられます。

絶対に外せない予定（結婚式、検査など）は「有給」を選んでください。

大量入力のコツ

  • 同じスタッフで連続して何日も指定できます（連休希望など）
  • 「希望休」を選んだ状態で別のスタッフに切り替えても、設定は維持されます
  • カレンダーは月単位の表示なので、月をまたぐ希望は次月に切り替えて入力
↑ 目次に戻る

③イベント

会議・研修・行事など、特定のスタッフが必ず出勤する日や、 特定のスタッフが必ず休む日を登録します。任意のステップです。

こんなときに使います

  • 月1回の病棟会議で主任は必ず出勤
  • 新人研修の日は研修担当者2名が出勤
  • 監査日は特定のメンバーがいる必要がある
  • 勉強会の日は受講予定者を休みにしたい

登録手順

  1. タブから 「③イベント」をタップ
  2. カレンダー上で イベント開催日をタップ
  3. 右側（スマホは下から出るパネル）でイベント情報を入力:
    • イベント名: 例「病棟会議」「新人研修」
    • 必須スタッフ: その日に必ず出勤する人を選択
    • 不可スタッフ: その日は必ず休みにする人を選択
  4. 「保存」をタップ
⚠️ イベントの制約は強力です

必須/不可スタッフは 必ず 反映されます。 矛盾がある（例：必須スタッフが希望休にも指定されている）と、 シフト生成が「実行不可能」になることがあります。

↑ 目次に戻る

④日別条件

各日に必要な日勤・夜勤の人数を設定します。初期値は日勤3名・夜勤2名。 特別な日（年末年始、繁忙日、閑散日）以外はそのままで構いません。

調整したいケース

  • 土日は日勤2名で十分 → 該当日の日勤を 2 に変更
  • 月末は忙しいので日勤4名にしたい → 月末の日勤を 4 に変更
  • 年末年始は夜勤1名で運営 → 12/31、1/1 の夜勤を 1 に変更

変更手順

  1. タブから 「④条件」をタップ
  2. 該当日の 日勤・夜勤の数字をタップ
  3. 「+」「−」ボタンで増減 または 数字を直接入力
  4. 変更は自動保存されます
💡 必要人数 × 日数 ≤ スタッフ提供可能枠

必要人数を増やしすぎると、生成が「実行不可能」になることがあります。 例：夜勤2名 × 31日 = 62回必要 → 夜勤可能スタッフ全員の上限合計が62以上必要。

⑤シフト生成

準備が整ったら、いよいよシフトを自動生成します。

生成手順

  1. 画面右上（スマホは上部中央）の 「シフト生成」ボタンをタップ
  2. 生成中はボタンが「生成中...」に変わり、最大1分待ちます
  3. 完了すると自動で 「⑤シフト表」タブに切り替わります
  4. 「シフトの生成が完了しました！」というメッセージが出ます
⏳ 生成中は画面を閉じないでください

最大55秒かかります。スピナーが回っている間はそのまま待ってください。 閉じても問題はありませんが、結果が表示されません。

「実行不可能」と表示されたら

制約が厳しすぎて、ルールを満たすシフトが組めない状態です。次のいずれかを試してください:

  1. 夜勤可能スタッフを増やす（スタッフ管理で夜勤可能のチェックを増やす）
  2. 夜勤上限を上げる（例 8 → 10）
  3. 必要人数を減らす（日別条件で夜勤を 2 → 1 にするなど）
  4. 有給を希望休に変更（有給は必ず割り当てなので、多すぎると人手不足に）
  5. イベントの必須/不可スタッフを見直す

⑥シフト表（確認・編集）

生成された1ヶ月分のシフトが表示されます。手動で修正することも可能です。

表示の見方

  • 縦軸: スタッフ
  • 横軸: 日付
  • 各セル: シフトコード（D / N / A / O / Y）
  • 色分けでひと目で分かるようになっています

スマホでの表示

画面が狭いため、デフォルトでは 「個人別表示」 になります。 1人分のシフトが大きく見やすく表示され、上下の矢印で前後のスタッフに切り替えられます。

上部の切替ボタンで「全体表示」に変えると、Excel風の全体表が見られます（横スクロール）。

手動編集

  1. 変更したい セルをタップ
  2. シフトコードの選択肢（D / N / A / O / Y）が表示
  3. 変更したいコードをタップ
  4. その場で反映されます（自動保存）
💡 手動編集の用途

自動生成された結果はベストではあっても完璧ではないことがあります。 「この人は今月忙しいから日勤に変えたい」「ここは別の人にしたい」など、 最終調整は手動で行うのが一般的です。

⚠️ 手動編集ではルールチェックされません

自動生成では「夜勤→明け」のルールが守られますが、 手動で N（夜勤）を入れても次の日が自動で A（明け）にはなりません。 必要に応じて自分で調整してください。

⑦集計

各スタッフの月間サマリーを確認します。偏りがないかチェックするためのページです。

表示される項目

  • 日勤(D): 日勤の回数
  • 夜勤(N): 夜勤の回数
  • 明け(A): 明けの回数（夜勤と同じ数になります）
  • 休み(O): 休日の回数
  • 有給(Y): 有給の回数

確認ポイント

  • 夜勤回数がスタッフ間で大きく偏っていないか
  • 休日が極端に少ない人がいないか（通常は月8〜10日）
  • 有給希望が反映されているか
💡 偏りが気になったら

シフト表に戻って手動で調整するか、 スタッフ管理で「夜勤上限」を調整して再生成してください。

月の切り替え

複数月のシフトを管理できます。直近3ヶ月分が自動保存されます。

切り替え手順

  1. 画面上部の 年月セレクタをタップ
  2. 表示したい月を選択
  3. その月のスタッフ・希望・シフト表に切り替わります
💡 前月の夜勤の引き継ぎ

前月のシフトを生成しておくと、月末の夜勤が 翌月1日の「明け」として自動的に引き継がれます。 連続夜勤が月をまたぐ場合も正しく処理されます。

⚠️ 4ヶ月以上前のデータは自動削除されます

端末の容量を節約するため、直近3ヶ月分のみ保存されます。 古いシフト表はスクリーンショットなどで残しておくと安心です。

複数人で使う

複数のスタッフ・複数の病棟が、同じURLでそれぞれ独立して使えます。

パターン1: それぞれが自分のスマホで使う

  1. 使う人全員に URL を共有（LINE、メール等）
  2. 各自が自分のスマホでアクセスし、自分用のワークスペースを作成
  3. お互いのデータは見えません（端末ごとに完全独立）

パターン2: 1台のスマホを複数人で共有

  1. 1台のスマホで、人数分のワークスペースを作成
  2. 各自に PINコードを設定させる（覗き見防止）
  3. 使い終わったら画面右上の 「👤名前」ボタンから切替

ワークスペースの切替方法

PC・タブレット

画面左上の「👤ワークスペース名」ボタンをクリック → 確認 → 切替画面に戻ります。

スマホ

画面右上の 「⋯」（三点リーダー）をタップ → メニューから 「ワークスペース切替」を選択。

🚨 同じワークスペースを複数端末で開かないでください

データはサーバに保存されないため、複数端末で同じ作業をすると、 最後に保存した方だけが残ります（同期されません）。 1ワークスペース = 1端末で使ってください。

データの安全性

Q. スタッフの名前など個人情報は安全ですか？

はい、安全です。すべてのデータはあなたのスマホのブラウザ内にのみ保存され、 サーバには一切送信されません。

Q. 通信は暗号化されていますか？

はい。URLは HTTPS（暗号化通信）で配信されています。 シフト生成のときだけサーバと通信しますが、生成結果を受け取った後にデータは破棄され、サーバには残りません。

Q. 他人にデータが見られることはありますか？

通常はありません。ただし以下の場合は注意:

  • スマホをロックしないで他人に渡した場合 → 中を見られる可能性があります（PINコード設定推奨）
  • 同じスマホで別のワークスペースを作った人 → ワークスペースが違えば見えません
  • ブラウザのプライベートブラウジングを使った場合 → タブを閉じると全データ消失

Q. データを完全に消したい

  1. 初期画面（ワークスペース一覧）に戻る
  2. 削除したいワークスペースの 「×」ボタンをタップ
  3. 確認ダイアログで「OK」を押す
  4. そのワークスペースのデータはすべて消去されます

Q. 機種変更したらデータはどうなる？

現在、データの移行機能はありません。新しい端末でゼロから作り直しになります。 どうしても引き継ぎたい場合は、スクリーンショットでシフト表を残しておくのが現実的です。 将来、エクスポート/インポート機能を追加する予定があります。

シフト記号の意味

シフト表に表示される記号と、その意味・ルールです。

記号 意味 ルール
D 日勤 通常の昼間勤務
N 夜勤 夜間勤務。翌日は必ず A（明け）になる
A 明け 夜勤明け。前日は必ず N、翌日は休みになりやすい
O 休み 通常の休日
Y 有給 希望入力で指定した日にのみ割り当てられる

夜勤の特別ルール

夜勤（N）は単独では入りません。必ず「N → A」の2日セットです:

  • 1日目: N（夜勤）
  • 2日目: A（明け）
  • 3日目: O（休み）になりやすい

トラブル時の対処

画面が真っ白で動かない

サーバが起き上がっている最中です。 無料プランの仕様で、15分間誰もアクセスしないとサーバがスリープします。 最初の人がアクセスすると30〜60秒かかります。閉じずに1分待ってください。

「シフト生成」ボタンを押しても何も起きない

  • スタッフが0人だと押せません（グレーアウト）→ スタッフ管理で1人以上登録
  • 生成中は最大1分の応答時間です → スピナーが回っているか確認
  • それでも動かない場合 → ブラウザを再読込（プルダウンで更新）

「実行不可能」と表示される

制約が厳しすぎる状態です。次のいずれかを試してください:

  • 夜勤可能スタッフを増やす
  • 夜勤上限を上げる（8→10など）
  • 日別条件で必要人数を減らす
  • 有給希望を希望休に変える
  • イベントの必須/不可スタッフを見直す

データが消えた・違うデータが表示される

  • 違うワークスペースを開いていないか確認（画面右上の名前を見る）
  • ブラウザの履歴・キャッシュを削除した場合 → データは完全に消えています
  • プライベートブラウジングモードで使った場合 → タブを閉じると消えます。通常モードで開き直す

ホーム画面のアイコンから開くと表示がおかしい

通常のブラウザから開き直してみてください。iPhone の Safari の「ホームに追加」は、 タブとは別の領域でデータを保持する場合があります。

PIN を忘れた

残念ですが、PINは暗号化されており復旧できません。 そのワークスペースを 削除して作り直す必要があります（データは失われます）。

よくある質問

無料で使い続けられますか？

はい。完全無料です。ただし、サーバの無料プランは15分アクセスが無いとスリープし、次回起動に30〜60秒かかります。これがどうしても気になる場合は有料プラン化を相談してください。

iPad でも使えますか？

はい。Safari や Chrome で同じ URL を開いてください。タブレットは画面が広いため、スマホよりも編集が快適です。

パソコンとスマホで同じデータを見られますか？

いいえ。データは端末ごとに独立しています。両方で使う場合は、それぞれのワークスペースを作るか、いつもどちらか一方で使ってください。

同じスマホで2人分のシフトを管理できますか？

はい。ワークスペースを2つ作ると、それぞれが独立したデータを持てます。画面右上の「👤名前」ボタンから切り替えてください。

生成結果が気に入りません

同じ条件で再生成しても、ほぼ同じ結果が出ます。希望や夜勤上限を少し変えて再生成するか、シフト表の手動編集で調整してください。

夜勤回数が偏ります

全員の「夜勤上限」を同じ数字に揃えると、バランスが良くなります。例：全員 max_night=8。

3交代制（早番・遅番・夜勤）に対応していますか？

現状は2交代（日勤・夜勤）対応です。3交代対応は将来のアップデート予定です。

シフトを印刷したい

シフト表のページをブラウザの印刷機能で印刷できます（横向きA4推奨）。スクリーンショットを保存するのも便利です。

Excel に出力できますか？

現状は対応していません。要望が多ければ追加します。

サンプル読込はどう使いますか？

機能を試したいときに使います。10名のスタッフと希望データが自動で入ります。試した後で「全消去」してから自分のデータを入れ直してください。

全消去ボタンを押したらどうなる？

そのワークスペース内のすべての情報（スタッフ・希望・シフト表）が消えます。確認ダイアログで「OK」を押すまで実行されません。

困ったときの連絡先は？

このアプリの管理者にご連絡ください。バグ報告や機能要望は喜んでお受けします。
